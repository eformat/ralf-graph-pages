RHOAI 3.6 Kitchen Sink: Feature Workshop Catalog

Welcome to the RHOAI Kitchen Sink — a hands-on workshop for every active feature in Red Hat OpenShift AI 3.6, organized by category with maturity badges.

3.6 GA refresh (2026-11-26): the catalog now tracks the 3.6 GA release feed — 175 feed items triaged, 74 feature rows added, 7 maturity bumps (see features/INGEST-3.6.md). New workshops appear in their category sections below; the flagship 3.6 workshop is Private Hugging Face models in the model catalog with its ▶ arcade walkthrough.

New to the catalog? Start with a curated Learning Path — ordered chains of workshops, from serving LLMs to governing the platform.

Setting up the workshop cluster? See Cluster Setup — the kustomize cluster/ config and which overlays each lab needs.

Maturity legend:

  • GA — Generally Available; fully supported, production-ready exercises

  • TP — Technology Preview; functional but not supported with production SLAs

  • DP — Developer Preview; provided as-is for evaluation
